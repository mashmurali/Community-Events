# 🌍 Local Community Events

A modern React-based web application that allows users to discover, filter, and join local community events such as workshops, meetups, music nights, and sports activities.

This project was built as part of a Frontend Developer Intern assignment.

---

## 🚀 Features

- Browse local events
- Filter by:
  - Type (Workshop, Music, Sports, Meetup, etc.)
  - Date
  - Location
- Search events by title
- Sort events by date
- RSVP / Join events
- Create & Host new events
- Clean desktop UI using TailwindCSS

---

## 🛠 Tech Stack

- React (Vite)
- React Router DOM
- Context API
- TailwindCSS
- Mock JSON Data

Proper Guide to Run / Setup the Project

## ⚙️ How to Run / Setup the Project

Follow these steps to run the project locally on your machine:

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/mashmurali/Community-Events/tree/master

2️⃣ Navigate into the Project Folder
cd local-community-events

3️⃣ Install Dependencies

Make sure you have Node.js (v16 or higher) installed.

Then run:

npm install


This will install all required packages.

4️⃣ Start the Development Server
npm run dev

5️⃣ Open in Browser

After running the above command, the app will start at:

http://localhost:5173


Open this URL in your browser to view the application.

🛑 To Stop the Server

Press:

Ctrl + C
